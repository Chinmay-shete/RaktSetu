Bridging Mock Frontend to Live Backend APIs Important Integration Steps

During frontend design, some local providers (like SystemAdminContext.jsx, HospitalContext.jsx, or mockApi.js) were configured with hardcoded mock arrays stored in localStorage.

To make the frontend completely alive with fresh backend data, you need to replace the local mock functions in the React context providers with actual HTTP calls.

Example: Bridging SystemAdminContext.jsx

Locate the mock functions (like approveHospital, approveOfficer, or toggleUserStatus) and replace them with standard fetch or axios calls to the port 5002 backend server. Make sure to attach the authenticated token header: 

// Example call to approve a pending hospital registration
const approveHospital = async (id) => {
  const token = localStorage.getItem('raktsetu_sysadmin_token'); // get token
  
  const res = await fetch(`http://localhost:5002/api/v1/systemadmin/hospitals/${id}/approve`, {
    method: 'PATCH',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    },
    body: JSON.stringify({ status: 'verified' })
  });

  if (res.ok) {
    // Refresh your React status state from the live backend
    await fetchPendingApprovals();
    await fetchUsersList();
  }
};
