What are these UI/UX styles? — for RaktSetu

Emil Kowalski Design Polish designer
Emil is a well-known product designer who focuses on micro-interactions, smooth animations, and very minimal clean aesthetics. His work feels "alive" — buttons respond gently, transitions are smooth, everything breathes.
Micro-interactionsSmooth animationMinimal clean UIMotion design
For RaktSetu: Use for button hover effects, loading states on blood search, smooth page transitions in the donor app.
Impeccable Design + Taste Skill Design philosophy
These are not tools — they are mindsets. "Impeccable Design" means obsessing over spacing, font weight, alignment, color balance. "Taste Skill" means developing the eye to judge what looks professional vs amateur. Think of Apple's Human Interface Guidelines.
Spacing & alignmentTypography hierarchyVisual refinementAttention to detail
For RaktSetu: Ensures your hospital dashboard doesn't look like a student project — consistent 8px grid, correct font sizes, no random colors.

Component Libraries (ready-made UI blocks)

Magic UI React
Animated React components — animated number counters, shimmer buttons, glowing cards, particle effects. Very popular for landing pages and hero sections.
AnimationReact componentsHero sections
RaktSetu hero landing page animated counters (blood units saved, hospitals connected)
Aceternity UI React
Beautiful, dramatic UI components — spotlight effects, 3D card tilts, moving borders, glowing grids. Dark-mode heavy. Very eye-catching for portfolios and product showcases.
3D effectsDark modeSpotlight cards
Use sparingly — maybe the login page or the public-facing landing page only. Too heavy for hospital dashboard.
21st.dev Recommended ✓
A community library of high-quality, copy-paste React + Tailwind components. Includes navbars, dashboards, tables, forms. Very practical for real apps, not just showoff projects.
Copy-pasteTailwind CSSPractical UI
Perfect for RaktSetu's hospital dashboard — blood stock tables, admin panels, search forms.
Mobbin Inspiration only
A library of real-world app screenshots from top apps (Airbnb, Uber, etc.). NOT a component library — it's pure visual inspiration. You look at it to get ideas, not copy code.
App screenshotsMobile patternsUX inspiration
Use to study how hospital/health apps layout dashboards and emergency screens before designing yours.
Layers Design community
Layers is a design community and resource hub — designers share UI kits, Figma files, templates, and tutorials. It's like GitHub but for design assets. You download Figma templates from here and adapt them.
Figma templatesUI kitsDesign resourcesCommunity
For RaktSetu: Download a healthcare or SaaS dashboard Figma kit and modify it to your design. Saves weeks of design time.
