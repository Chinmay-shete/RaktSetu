1
Phone verification Identity — before anything else
Mobile number Required
10-digit · +91 prefix
Primary identity. Used for OTP login, WhatsApp alerts, and SMS notifications. This IS your account.
OTP code Required
6-digit · Auto-expire 5 min
Proves the phone number belongs to them. Prevents fake registrations with someone else's number.
2
Basic profile Who they are
Full name Required
Text · 2–60 chars
Shown to hospital when donor responds to an urgent request. Hospital needs to know who is coming.
Age Required
Number · 18–65 only
Legal eligibility. Below 18 or above 65 cannot donate blood in India per NBTC guidelines. Block them upfront.
Gender Required
Male / Female / Other
Females have a weight and haemoglobin threshold that differs from males. Affects eligibility check logic.
Blood group Required
Dropdown: O+/O−/A+/A−/B+/B−/AB+/AB−
The most critical field. This is how the system matches the donor to a hospital that urgently needs that exact group.
3
Location Where they are
City Required
Text with autocomplete
Used to show nearby donation camps and hospitals. Without this the app cannot show anything relevant to them.
Pincode Required
6-digit number
More precise than city. Lets the system calculate real distance to the nearest hospital needing their blood group.
GPS / live location Optional
Device permission prompt
If they allow it — shows the exact nearest hospital in real time. If they deny — pincode is used as fallback.
4
Donation history Eligibility calculation
Have you donated before? Required
Yes / No toggle
First-time donors need a different onboarding message. Returning donors need last donation date to calculate eligibility.
Date of last donation Optional
Date picker (shown only if donated before = Yes)
NBTC rule: must wait 90 days between donations (56 days for platelets). This calculates exactly when they can next donate and shows a countdown.
Type of last donation Optional
Whole blood / Platelets / Plasma
Each has a different waiting period. Whole blood = 90 days. Platelets = 14 days. Plasma = 28 days. Changes the eligibility countdown.
5
Health quick-check Basic eligibility screening — not medical advice
Weight above 45 kg? Required
Yes / No
NBTC minimum weight rule. Below 45 kg = cannot donate. If No — show a polite ineligibility message and block.
Any chronic illness? Required
Yes / No · If Yes → which (optional text)
Diabetes, HIV, Hepatitis B/C, Heart disease = permanent or temporary deferral. System flags these and does not match them to urgent requests.
Taken any medication in last 7 days? Optional
Yes / No
Antibiotics or blood thinners = temporary deferral. Optional because most donors won't have this and it adds friction.
Pregnant or breastfeeding? Optional
Shown only if gender = Female
Pregnancy and 6 months post-delivery = cannot donate. Must be shown to female donors, hidden for male to reduce clutter.
6
Notification preferences How to reach them
Notify when blood group needed urgently Required
Toggle — default ON
Core purpose of the app. Must be ON by default. If they turn it OFF they are not usable as an emergency donor.
Notify about donation camps nearby Optional
Toggle — default ON
Drives proactive donations, not just emergency ones. Can be turned off by those who only want emergency alerts.
Notification channel Required
WhatsApp / SMS / Both (radio select)
Not all donors have WhatsApp. SMS is the fallback for rural donors with basic phones. Must offer both options.
Available to donate right now Optional
Toggle — default ON
Lets donor pause availability when travelling, sick, or busy. System skips them for matching during OFF period without deleting their account.
